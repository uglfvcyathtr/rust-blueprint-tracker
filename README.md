## Overview

Rust Blueprint Tracker is a companion web app for the survival game Rust that tracks which crafting blueprints have been unlocked on a character, highlights missing blueprints by category, calculates the scrap cost to research remaining items, and supports multi-account tracking so team members can coordinate blueprint coverage.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Rust Blueprint Tracker** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Blueprint Log** | Track all unlocked blueprints organized by workbench tier |
| **Missing Blueprints** | Highlights uncollected blueprints with research scrap cost |
| **Scrap Calculator** | Calculates total scrap needed to complete any blueprint category |
| **Team Tracking** | Track multiple accounts to coordinate team blueprint coverage |
